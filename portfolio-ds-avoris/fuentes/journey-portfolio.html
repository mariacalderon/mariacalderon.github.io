Web Components with AI, in our own repository

  • AI turns each Figma component into a Web Component.
  • Before creating anything, it checks what already exists and builds the new component from existing pieces, so nothing is duplicated.
  • It follows our rules, uses tokens and checks the result against Figma.
  • A living reference we can check, but not production code yet.
