How it works
AI connects Figma and code in both directions, so design and code stay in sync.
Direction 1

Figma → code

Starting from a Figma link, AI:
1

Reads

The component: sizes, colors, variants and the variables behind them.

2

Checks

If a similar component already exists, so there are no duplicates.

3

Builds

A Web Component with the same name as in Figma and tokens, without fixed values.

4

Reuses

Smaller components to build it, like in Figma.

5

Tests

Opens it in the browser and compares it with Figma.

6

Records

Saves notes and a record of the changes.

Direction 2
